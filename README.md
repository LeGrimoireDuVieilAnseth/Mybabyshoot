# Mybabyshoot

Site vitrine et reservation pour Mybabyshoot, photographe grossesse, naissance et nouveau-ne a Lyon.

## Etat actuel

Site en un seul fichier `index.html` (HTML, CSS et JS inline), avec un dossier `images/`. Hebergement prevu sur Netlify (glisser-deposer du dossier complet). Le site contient :

- un hero avec mise en avant de la marque "Matt la photo"
- une bande de reassurance et des statistiques (dont un badge avis Google)
- des avis clients
- une galerie justifiee (grossesse, naissance, famille)
- une section "Le photographe"
- une section "Tout est deja inclus"
- un comparateur avant / apres retouche
- un configurateur de seance sur mesure qui calcule un prix en direct
- un systeme de reservation via une fenetre Koalendar (a remplacer, voir taches)
- un formulaire de contact
- un pied de page

## Lancer en local

Aucune dependance pour la version actuelle. Ouvrir `index.html` dans un navigateur. Important : garder `index.html` et le dossier `images/` ensemble, sinon les photos ne s'affichent pas.

## Deploiement

Netlify, en glissant le dossier complet (index.html + images) dans la zone de deploiement. Ne jamais envoyer le fichier seul.
